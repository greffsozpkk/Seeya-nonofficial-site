# SEEYA ARCHIVE v3.0

이번 수정:
- 스케줄 로딩을 브라우저 fetch(CSV) 방식에서 Google Visualization JSONP 방식으로 변경했습니다.
- 카드 상세는 '이미지 위 / 설명 아래'의 세로형 레이아웃으로 변경했습니다.
- 메인 핑크 SEEYA 로고를 사용자 원본 PNG의 알파 실루엣에서 다시 벡터화하여, 기존 SVG의 모양 깨짐을 수정했습니다.
- 로고 그림자와 변형 효과를 모두 제거했습니다.

## 스케줄이 그래도 안 뜨는 경우
Google Sheets에서:
파일 → 공유 → 웹에 게시 → 해당 시트(gid=0) 게시
를 한 번 설정해주세요.

단순 '링크가 있는 모든 사용자 = 뷰어'보다 '웹에 게시'가 정적 GitHub Pages에서 외부 데이터로 읽을 때 더 안정적입니다.
