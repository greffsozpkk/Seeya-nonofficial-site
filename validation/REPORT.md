## 기능

- 퀴즈 3개 난이도, 총 30문제 완주. 135문제 데이터 확인.
- Level 2·3 첫 오답 앨범 힌트, 두 번째 정답 점수 제외, 결과 3줄, 재시작·초기화.
- ARCHIVE 검색·카테고리·정렬·페이지 이동·초기화. 검색어 HTML 이스케이프.
- NEWS 4개 분류.
- FANCHANT 12개 이미지·확대·키보드 이동·닫기.
- GALLERY 테스트 데이터 2개를 주입해 목록·확대·키보드 이동·닫기 확인. 납품 JSON에는 테스트 데이터 없음.
- 일반 링크·직접 진입·새로고침·기존 해시 북마크.
- 숨겨진 타로 키 입력·모달 유지.
- JS OFF 11개 경로 본문 표시. 뉴스 기사, 아카이브 9건, 응원법 12개가 초기 HTML에 존재.

functional-results.json 참조. 스와이프 이벤트는 원본 구현을 보존했으며 실제 터치 기기 검사는 하지 않았습니다.
