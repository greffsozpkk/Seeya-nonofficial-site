# 씨야 라이브 도감

2026-11-25. 공개 주소 `/music/live/`. MUSIC 메뉴에서 연결한다.

## 실행

같은 터미널 환경에서 `node build.js --preview` 후 `node scripts/serve.js 8201 --preview`.
주소: http://127.0.0.1:8201/music/live/test/
일반 `node build.js`는 `/music/live/` 공개 페이지·검색용 사이트맵·PWA 경로를 생성한다. 테스트 경로는 로컬 미리보기에서만 유지한다.

## 현재 범위

- THE FAN 8회차. 서울 8월 29일과 30일은 별도 회차다.
- 씨야 발표곡 25곡, 기존 아카이브 영상 제목을 대조한 131개 곡·회차 연결.
- 회차별 목록, 두 공연 비교, 전체 비교표, 곡명·앨범 검색, 12곡씩 페이지 이동.
- 자료 창의 표준 YouTube 임베드, 원본 링크, 곡별 무대, 다이어리 공연 기록 연결.
- 다이어리는 기존 기록을 읽거나 작성 화면으로 이동한다. 가창 곡을 자동 저장하지 않는다.

영상 제목과 날짜·지역을 대조한 초안이다. 영상 전편을 직접 검수한 완전한 셋리스트가 아니며, 멤버 명의 별도 솔로곡 및 외부 커버곡은 후속 범위다. 근거가 없는 셀은 미공연이 아닌 확인 중이다. 한쪽만 확인된 곡도 해당 회차의 독점곡으로 단정하지 않는다.

## 자료 유지

`src/data/live-evidence.json`은 안정적인 곡 ID·회차 ID·기존 아카이브 ID·근거 URL만 연결한다. 제목과 앨범은 곡 목록에서, 출처 정보는 아카이브에서 가져온다. 숨긴 기록 또는 삭제한 출처는 제외한다. 동일 곡의 동일 회차 자료가 여러 개여도 횟수는 1회다.

`scripts/prepare-live-preview.cjs`는 초기 검토 후보를 만드는 보조 도구다. 실행하면 연결 파일을 다시 쓰므로, 추가 수집 결과는 원본 제목과 실제 공연 날짜를 검토한 뒤 반영한다. 게시일을 공연일로 사용하지 않는다. 전체 셋리스트가 확인되지 않은 회차에는 미공연 판정을 넣지 않는다.

## 확인

`node scripts/check-live-atlas.js`: 서울 날짜 분리, 중복 집계 방지, 숨긴 자료·누락 출처 제외, 일부 영상, 근거 없는 미공연 판정 방지.
`node scripts/check.js`: 기존 공개 빌드 재현성과 전체 회귀 검사 통과.
브라우저: 390px 모바일 목록·비교, 검색, 근거 창, 뒤로 가기, 다이어리 작성 연결 확인. 실제 휴대전화 검증은 미실시.

## 11월 24일 영상 교체

초기 연결 39개를 같은 회차의 긴 무대 영상으로 교체했다. 새로 찾은 서울 8월 30일 `그래도 좋아`(4:21)는 기존 서울 공연 기록의 추가 출처로 보존했다. 모든 선택 영상에 확인한 재생 시간을 저장하고 화면에도 표시한다. 짧은 클립 12개는 대체본 미확인으로 남아 있으며 일부 영상 표시를 한다. 영상 길이만으로 완곡임을 보증하지 않는다. 두 곡 이상 포함한 영상은 원본 제목으로 구분한다.

조회 결과와 남은 짧은 영상 목록은 `output/live-video-audit/`에 보관한다. 원본 메타데이터 조회 실패는 영상 부재로 판단하지 않았으며, 대체 후보는 실제 YouTube 플레이어의 시간 표시도 대조했다. 운영자 자료의 계정 정보나 비공개 데이터는 페이지에 포함하지 않는다.

11월 25일 로컬 미리보기의 MUSIC 하위 메뉴에 `라이브 도감`을 네 번째로 추가했다. 음반·곡별 무대·응원법·도감에서 공통으로 표시하며, 모바일 850px 이하에서는 2×2, PC에서는 한 줄로 배치한다. 공개 빌드에도 동일한 네 메뉴를 표시하며 `/music/live/`로 연결한다.

11월 25일 화면의 ‘가창’을 ‘무대’로 통일했다. 상단 타이틀은 YES24 서울 공연 안내 포스터를 바탕으로 이미지 편집 도구로 배경을 제거한 투명 PNG를 사용한다. 사진·장식과 카드 배경을 제거하고 두 줄의 타이틀만 표시한다. 원본 포스터도 별도로 보관한다.
